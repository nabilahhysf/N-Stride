
# N-Stride
## Personal Task Management System

N-Stride is a simple web-based task management system developed for the IMS566 assignment.

## Features
- Login and logout
- Dashboard with task summary
- Task progress chart
- View and manage tasks
- Add and delete tasks
- Search and filter tasks
- Task categories

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap 5
- Chart.js

## Demo Login

## How to Run
1. Download or clone the repository.
2. Open index.html using Google Chrome.
3. Login using the demo credentials.

## Note
This project uses sample data and does not require a database or PHP.
